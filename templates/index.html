⏳ Checking credentials…
You only need to do this once. After setup, emails are parsed automatically.
  1. 1 Go to console.cloud.google.com → Create a new project (e.g. "JobTracker")
  2. 2 In the project, search for Gmail API and click Enable
  3. 3 Go to APIs & Services → Credentials → Create Credentials → OAuth client ID
  4. 4 Choose Desktop app as the application type → Create
  5. 5 Click Download JSON — rename it to credentials.json
  6. 6 Place credentials.json in the job-tracker\ folder (same folder as app.py)
  7. 7 Click Sync Emails — a browser window will open to authenticate with Google (one-time). After that, syncing is fully automatic.
Privacy note: credentials are stored locally on your PC. Only your Gmail labels/subjects are read — no email content is sent anywhere.
